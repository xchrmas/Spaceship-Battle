## 🌌 What is Spaceship Battle?

**Spaceship Battle** is an action-packed space shooter forged in **Unity** with **C#** at its core. Navigate the cold, merciless cosmos, annihilate waves of incoming enemy spacecraft, and push your reflexes to the absolute limit.

Built with a custom **ShaderLab** visual pipeline that makes space *feel* alive — with glowing energy trails, explosive particle bursts, and deep-space atmosphere that pulls you in from the very first second.

No loading screens between you and chaos. **Just launch and fight.**

## 🚀 Getting Started

### 🎮 Play in Browser (Instant)

> No setup needed. Just open and play.

```
🌐 WebGL Build → /WebGL_Build/index.html
```

Open the `WebGL_Build/index.html` file in any modern browser and start fighting.

---

### 🖥️ Run in Unity Editor

**Prerequisites:**
- [Unity Hub](https://unity.com/download)
- Unity **2022.x** or newer
- [JetBrains Rider](https://www.jetbrains.com/rider/) *(recommended)* or Visual Studio

**Clone & Open:**

```bash
# Clone the repository
git clone https://github.com/xchrmas/Spaceship-Battle.git

# Open in Unity Hub
# File → Open Project → Select the cloned folder
```

```bash
# Or open directly with Unity
unity -projectPath ./Spaceship-Battle
```
